# Benjamin De Paolo

Portfolio personal: proyectos, trayectoria y contacto.

Sitio estático en HTML, CSS y JavaScript, preparado para GitHub Pages. No requiere instalación de dependencias ni compilación.

- `index.html`: presentación y proyectos.
- `sobre-mi.html`: trayectoria, formación e intereses.
- `proyectos/`: páginas de los proyectos.
- `assets/`: estilos y funciones del sitio.
- `images/`: fotografías y portadas utilizadas.
- `404.html`: página de error.
- `CNAME`: dominio personalizado.
- `.nojekyll`: publicación directa de los archivos estáticos.

El contenido se edita directamente en los archivos HTML.
